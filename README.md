# База знаний тренера CBSD

Одностраничный статический сайт с информацией для тренеров CBSD.

## Структура проекта

```
CBSD/
  index.html      # Главная страница
  styles.css      # Стили
  script.js       # Плавная прокрутка по якорям
  assets/
    img/
      bg/         # Фоновые изображения
      logo/       # Логотипы
      ui/         # Иконки и UI-элементы (если появятся)
    fonts/        # Шрифты (Lato)
  README.md
```

## Разделы

1. **Миссия и ценности**
2. **Пакет тренера**
3. **Рост и развитие**
4. **Деньги и документы**
5. **Контакты**

## Технические требования

- Чистый HTML/CSS/JS без фреймворков и сборки
- Адаптивность: desktop, tablet, mobile
- Fixed background (фиксированный фон при прокрутке)
- Плавная прокрутка к разделам по клику на кнопки

## Запуск

Откройте `index.html` в браузере — сайт работает локально без сервера.
